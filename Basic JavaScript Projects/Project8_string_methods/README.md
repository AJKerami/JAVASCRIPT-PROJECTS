# Project 8: String Methods — in progress

Implemented from the Module 3 assignment text:

- `concat()` joins strings into a sentence.
- `slice()` extracts a name from a sentence.
- `toUpperCase()` produces uppercase text.
- `search()` finds the position of a regular-expression match.
- `toString()` converts a number to a string.
- `toPrecision()` formats a number as a string with a specified number of significant digits.
